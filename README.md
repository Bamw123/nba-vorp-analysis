# NBA Player Value Analysis (2024–25 Season)

A semester-long statistics project exploring what drives player value — measured by VORP (Value Over Replacement Player) — in the 2024–25 NBA regular season.

## Dataset

- **Source:** Merged from three sources — [Basketball-Reference Per Game stats](https://www.basketball-reference.com/leagues/NBA_2025_per_game.html), [Basketball-Reference Advanced stats](https://www.basketball-reference.com/leagues/NBA_2025_advanced.html), and [RealGM's 2024–25 player list](https://basketball.realgm.com/nba/players/2025).
- **Topic:** Individual NBA player performance and value during the 2024–25 regular season.
- **Size:** 569 players, with categorical variables (Position, Conference, Nationality, Draft_Group) and continuous variables (points, rebounds, assists, steals, blocks, shooting percentages, and more).
- **Main research question:** Which player statistics best predict VORP, and can we build a reliable model of what makes an NBA player valuable?

## What's in this repo

- `data/` — the raw/cleaned dataset used throughout the project.
- `assignment-02-dataset/` — dataset selection and write-up (Assignment 2).
- `assignment-03-descriptive-stats/` — descriptive statistics, frequency tables, and visuals (Assignment 3).
- `assignment-04-probability/` — distribution analysis and probability work (Assignment 4).
- `assignment-05-inference/` — hypothesis testing and confidence intervals (Assignment 5).
- `assignment-06-regression/` — multiple linear regression, multicollinearity checks, and the final predictive model (Assignment 6).
- `DECISIONS.md` — a dated log of the key analytical decisions made at each stage of the project.
